# SDG Hackathon Project

## Overview

This is a project developed for the SDG (Sustainable Development Goals) Hackathon finals. The project combines multiple technologies to create a comprehensive solution addressing sustainable development challenges.

## Tech Stack

- **TypeScript** (59.1%) - Core application logic and type-safe development
- **Python** (39.5%) - Data processing and backend services
- **CSS** (1.3%) - Styling and user interface
- **Mako** (0.1%) - Template rendering

## Features

- Sustainable development goal tracking and monitoring
- Data-driven insights and analytics
- User-friendly interface for goal management
- Backend services for data processing

## Getting Started

### Prerequisites

- Node.js and npm (for TypeScript/JavaScript components)
- Python 3.x (for Python components)
- Git

### Installation

1. Clone the repository:
```bash
git clone https://github.com/sundarammss/SDGhackathon.git
cd SDGhackathon
```

2. Install dependencies:

For Node.js/TypeScript:
```bash
npm install
```

For Python:
```bash
pip install -r requirements.txt
```

### Development

To run the project in development mode:

```bash
npm start
```

### Building

To build the project for production:

```bash
npm run build
```
